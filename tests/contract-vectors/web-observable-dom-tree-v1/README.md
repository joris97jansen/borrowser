# Web-observable DOM tree V1 contract vectors

These fixed UTF-8/LF bytes are hand-authored from the frozen grammar in
`docs/conformance/ag9-cross-engine-comparison-reporting.md`. They are read-only
oracles shared by independent Rust and JavaScript implementations. Neither
producer generates them. Changes require review against the written contract;
serializer output is not authority to update an expectation.

The node/attribute/template vectors describe the observation grammar, including
states constructible for codec tests but not necessarily generated by text/html
parsing (two doctypes, actual PI nodes, ordinary template children). Producer
setup is authored independently, never recovered from these expected bytes.
`static-document.txt` describes the existing dom-tree-basic fixture;
`static-document-different.txt` is an independently authored empty document.
Neither is a real external browser capture.

This directory is outside `tests/conformance/fixtures`, the AG2 discovery root.
It contains no AG2 descriptors and is not an execution package or AG manifest
member. Rust and JavaScript tests resolve it read-only from their source paths.
